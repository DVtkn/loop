# AGENTS.md — Правила, архитектура и инструкции для AI-агентов
**Версия:** 3.0.0  
**Статус:** Единый Источник Правды (SSOT)

Этот файл содержит фундаментальные правила, архитектурные соглашения и стандарты разработки проекта **Loop** (приложение для двоих с психологическими исследованиями, виртуальным питомцем Тамагочи, Большой Красной Кнопкой касания и поддержкой ИИ-психолога «Сова»).

---

## 1. Absolute Constraints (Категорические запреты)

1. ❌ **ЗАПРЕЩЕНО** использовать моковые данные, заглушки со статическими процентами (58%, 59%, 65%) и константы вида «Dmitry и Anna завершили 7 из 7» в продакшен-коде. Если в базе нет отчёта, UI обязан отображать пустое состояние (Empty State).
2. ❌ **ЗАПРЕЩЕНО** использовать слово «якорь» в любых сгенерированных названиях, архетипах союза или fallback-значениях. Архетипы формируются строго как комбинация двух ведущих сфер (например, «Надёжная гавань & Общий горизонт»).
3. ❌ **ЗАПРЕЩЕНО** использовать `db_store.json` в продакшене. В качестве базы данных используется ТОЛЬКО Neon PostgreSQL + Drizzle ORM.
4. ❌ **ЗАПРЕЩЕНО** удалять или сжимать Большую Красную Кнопку («Обнять») в мелкую плашку списка. Это главная эмоциональная киллер-фича мгновенного контакта пары.
5. ❌ **ЗАПРЕЩЕНО** раскрывать ответ партнёра на вопрос дня до ответа текущего пользователя (Blind Reveal Principle).
6. ❌ **ЗАПРЕЩЕНО** допускать горизонтальный скролл ($>0\text{px}$ overflow-x) и шрифты инпутов менее $16\text{px}$ на мобильных устройствах (во избежание автозума в Safari iOS).

---

## 2. Архитектурные правила и доменные сущности

1. **Виртуальный питомец союза (`couple_pets`)**:
   - Роуты `/api/pet/*` (birth, action, propose-name, confirm-name, switch).
   - Действия заботы: `feed`, `play`, `wash`, `sleep`, `hug`.
   - Серверный расчет decay параметров угасания и ночной режим сна.
   - Realtime оповещение через SSE (`pet_updated`).
2. **Большая Красная Кнопка («Обнять»)**:
   - Располагается верхним Hero-элементом на `DashboardView`.
   - Сопровождается тактильной отдачей Haptic (`navigator.vibrate`), звуком сердца через Web Audio API и Web Push уведомлением.
3. **Изоляция данных союза (IDOR Prevention)**:
   - Доступ ко всем данным союза проверяется через `requirePairOwnership`.
   - `pairKey` = `[login, partnerLogin].sort().join('_')`. Доступ чужих пар запрещён (403 Forbidden).
4. **Изоляция вкладок аналитики (Tabs Isolation)**:
   - При `activeTab === 'partner'` рендерить ТОЛЬКО личные шкалы партнёра (если сданы) или карточку ожидания с ранним выходом (`return`). Запрещено просачивание совместного радара в личную вкладку.

---

## 3. Стандарты мобильного дизайна и вёрстки (Mobile-First)

1. **Тач-таргеты**: Все кликабельные элементы на смартфонах обязаны иметь область нажатия не менее $40\times 40\text{px}$ (включая иконки колокольчика и темы в хедере).
2. **Формы и инпуты**: Все `<input>` и `<textarea>` обязаны иметь `font-size: 16px` на мобильных экранах для предотвращения автозума в iOS Safari.
3. **Навигация**: Мобильный bottom bar фиксирован внизу с учётом `safe-area-inset-bottom`. В режиме полноэкранного чата нижний таб-бар автоматически скрывается (`body.in-chat-view .bottom-nav`).
4. **Тексты**: Никакого ALL CAPS. Текст не обрезается многоточием (`truncate`), а переносится на вторую строку (`line-clamp-2` или `break-words`).
5. **Иконки**: Все иконки обязаны иметь пастельную подложку с семантическим цветом (`background: token.text + '18'`).

## 4. Testing & Verification Standard (DoD)

Перед каждым коммитом в репозиторий агент обязан выполнить:
1. `npm run test:tsc` — 0 ошибок типов TypeScript.
2. `npm run test` — прогон Vitest юнит-тестов (все тесты зелёные).
3. `npm run build` — чистая сборка клиента и сервера для Vercel.
4. Верификацию двустороннего сценария (пользователь А инициирует действие → пользователь Б видит результат без рассинхронизации).

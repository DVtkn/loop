**Версия:** 2.3.0  
**Статус:** Утверждён

## 1. Миссия и детерминированность аналитики

Приложение **Loop** предназначено для укрепления отношений и эмоциональной близости пары с использованием научной психометрики и поддержки ИИ-психолога.

- **Детерминированность**: Аналитика союза строится СТРОГО на математических формулах и экспертных матрицах правил в PostgreSQL. Никаких «галлюцинирующих» LLM для вычисления совпадений или генерации радара.
- **Терминология**: Запрещено использовать термин «ИИ-отчёт» для аналитических экранов. Раздел называется строго **«Аналитика союза»**.
- **Названия архетипов**: Запрещены любые упоминания слова «якорь». Названия архетипов формируются комбинацией двух ведущих сфер (например, «Надёжная гавань & Общий горизонт», «Глубокий контакт & Взаимная опора»).
- **Антиманпулятивная методология**: Все тесты используют принудительный выбор (Ipsative Forced-Choice) между равными ценностями или естественными защитными реакциями. Нет шкал согласия (1–5), нет «правильных» ответов.

## 2. Психометрическая архитектура

### 2.1 Матрица переменных: 24 первичные шкалы → 6 интегральных сфер

| Сфера | Первичные шкалы (S₁…S₂₄) | Психометрический смысл |
|-------|-------------------------|------------------------|
| **1. Доверие и безопасность** | S₁ Тревожность привязанности (ECR-R) • S₂ Избегание близости (ECR-R) • S₃ Базовый уровень подозрительности • S₄ Допуск партнёра к уязвимости | Внутренняя готовность открываться без страха отвержения или поглощения |
| **2. Эмоциональная близость** | S₅ Слова и валидация • S₆ Время и внимание • S₇ Помощь и забота • S₈ Физический контакт | Совпадение «входных» и «выходных» каналов эмоционального подкрепления |
| **3. Конфликтная динамика** | S₉ Преследование (Pursuit) • S₁₀ Отстранение (Withdrawal) • S₁₁ Реактивная критика/сарказм • S₁₂ Скорость остывания | Автоматические бессознательные реакции в стрессе |
| **4. Ценности и горизонт** | S₁₃ Автономия vs слияние • S₁₄ Материальные амбиции vs комфорт • S₁₅ Дети и воспитание • S₁₆ Традиции и внешняя семья | Долгосрочная мировоззренческая совместимость |
| **5. Интимность и страсть** | S₁₇ Эмоциональный триггер возбуждения • S₁₈ Спонтанность vs предсказуемость • S₁₉ Инициативность • S₂₀ Табуированность желаний | Баланс эротического влечения, безопасности и открытости |
| **6. Быт и жизнестойкость** | S₂₁ Контроль и порядок (Big Five C) • S₂₂ Совместные финансы • S₂₃ Социальная батарейка (Big Five E) • S₂₄ Готовность к внешним кризисам | Устойчивость к рутине, бытовым задачам и стрессу среды |

### 2.2 Двухуровневый алгоритм агрегации

```
Уровень 1: Сырые ответы U₁, U₂
    ↓ (нормализация шкал 0..100)
Уровень 2: Индивидуальные векторы V₁, V₂ (24 шкалы)
    ↓ (кросс-матричное сведение: дельта + синергия)
Уровень 3: 6 сфер Радара + Архетип союза
```

**Уровень 1 → 2 (Индивидуальная нормализация):**

$$S_k = \left( \frac{\sum_{j=1}^{M_k} w_{kj}}{\text{MaxPossible}_k} \right) \times 100, \quad S_k \in [10; 100]$$

**Уровень 2 → 3 (Сведение в 6 сфер):**

*Для сфер с требованием конгруэнтности (Ценности, Быт, Конфликты):*
$$\Delta_{sphere} = \frac{1}{N} \sum_{k \in Sphere} |S_k^{U1} - S_k^{U2}|$$
$$\text{Score}_{sphere} = \max(10,\; 100 - (\Delta_{sphere} \times 1.25))$$

*Для сфер с взаимодополняемостью (Близость, Доверие, Интимность):*
$$\text{Score}_{sphere} = 100 - \Delta_{sphere} + \text{SynergyBonus}$$
*Штраф за деструктивный паттерн:* если $S_9^{U1} \ge 65$ и $S_{10}^{U2} \ge 65$ (или наоборот) → $-20\%$ за паттерн «Преследователь ↔ Дистанцирующийся».

### 2.3 6 интегральных сфер Радара

| Сфера | Компоненты | Формула |
|-------|-----------|---------|
| **Trust (Доверие)** | S₄, S₃, S₁, S₂ | $\text{Trust} = \text{clamp}(0.45\bar{S}_4 + 0.35\bar{S}_{\text{susp}} + 0.2(100-\Delta_{\text{att}}))$ |
| **Closeness (Близость)** | S₅…S₈ | $\text{Closeness} = \text{clamp}(0.6\bar{S}_{\text{chan}} + 0.2\text{Match}_\text{touch} + 0.2\text{Match}_\text{time})$ |
| **Communication (Общение)** | S₉…S₁₂ | $\text{Comm} = \text{clamp}(0.55\bar{S}_{12} + 0.45\bar{S}_{11\text{low}} - 20\cdot[\text{Pursuit-Withdrawal}])$ |
| **Values (Ценности)** | S₁₃…S₁₆ | $\text{Values} = \text{clamp}(0.4\bar{S}_{15} + 0.6(100 - \text{Penalty}_\text{delta}))$ |
| **Intimacy (Интимность)** | S₁₇…S₂₀ | $\text{Intimacy} = \text{clamp}(0.35\bar{S}_{17} + 0.25\bar{S}_{19} + 0.2\bar{S}_{20} + 0.2(100-\Delta_{18}))$ |
| **Lifestyle (Быт)** | S₂₁…S₂₄ | $\text{Lifestyle} = \text{clamp}(0.4\bar{S}_{24} + 0.6(100 - 0.4\Delta_{21} - 0.4\Delta_{22}))$ |

## 3. Банк антиманпулятивных тестов (6 модулей + Personality Type)

### Форматы вопросов
- **Формат A (Ipsative Forced-Choice)**: два равноценных позитивных варианта — вынужденный выбор
- **Формат B (Forced Vulnerability)**: выбор между естественными защитными реакциями, нет «идеального дипломата»
- **Формат C (Trade-off Matrix)**: распределение 10 баллов между 3–4 аспектами

### Модуль 1. Стресс-контур и автоматические защиты (ECR-R + ЭФТ)
**Шкалы:** S₁, S₂, S₉, S₁₀  
**Ситуация 1.1:** Партнёр приходит домой в напряжении, отвечает сухо: «Всё нормально, отстань».  
**Варианты:**
- A: Физически ухожу в другую комнату, жду, пока сам заговорит *(Отстранение)*
- B: Внутри тревога, настойчиво спрашиваю: «Что случилось?» *(Преследование)*
- C: Обижаюсь, закрываюсь, общаюсь так же сухо *(Скрытый протест)*
- D: Пытаюсь сгладить: суечусь, предлагаю чай/шутку *(Умиротворение)*

### Модуль 2. Архитектура заботы (Адаптивный Чепмен)
**Шкалы:** S₅, S₆, S₇, S₈  
**Ситуация 2.1:** У вас был сложный день, вы опустошены. Что реально вернёт силы?  
**Варианты:**
- A: Партнёр молча забирает быт: еда, посуда, «Отдыхай» *(Дела/Помощь)*
- B: Партнёр откладывает телефон, обнимает, гладит, пока прихожу в себя *(Физический контакт)*
- C: Партнёр говорит: «Вижу, как тебе тяжело. Ты справишься, горжусь тобой» *(Слова признания)*
- D: Партнёр предлагает поехать в тихое место, поговорить вдвоём *(Качественное время)*

### Модуль 3. Границы «Я» и «Мы» (Дифференциация Боуэна)
**Шкалы:** S₁₃, S₂₃  
**Ситуация 3.1:** Партнёр хочет недельный отпуск отдельно.  
**Варианты:**
- A: Полная поддержка — у каждого своё пространство *(Высокая дифференциация)*
- B: Внешне согласен, внутри сомнения: «Почему ему хорошо без меня?» *(Скрытая тревога)*
- C: Недоумение — отпуск пары это святое время для двоих *(Стремление к слиянию)*
- D: Сразу планирую свой график, чтобы не чувствовать себя брошенным *(Компенсаторная автономия)*

### Модуль 4. Финансово-бытовой код
**Шкалы:** S₁₄, S₂₁, S₂₂  
**Ситуация 4.1:** Появилась крупная сумма.  
**Варианты:**
- A: Инвестировать/накопительный счёт — безопасность будущего *(Контроль)*
- B: Потратить на яркие впечатления — пока молоды *(Спонтанность)*
- C: На комфорт дома, ремонт, практичные вещи *(Прагматизм)*
- D: Разделить поровну на личные счета без отчётов *(Автономия)*

### Модуль 5. Интимность, уязвимость, контакт
**Шкалы:** S₁₇, S₁₈, S₁₉, S₂₀  
**Ситуация 5.1:** Главное предварительное условие для глубокого сближения?  
**Варианты:**
- A: Эмоциональная безопасность за день: нет обид, тепло, нежные взгляды *(Эмоциональный разогрев)*
- B: Спонтанность, игра, смена обстановки *(Эротическая автономия)*
- C: Прямая инициатива и страстное подтверждение желанности *(Подтверждение влечения)*
- D: Физический комфорт, отсутствие усталости *(Телесная готовность)*

### Модуль 6. Ценностный компас (Шварц)
**Шкалы:** S₁₅, S₁₆, S₂₄  
**Ситуация 6.1:** Через 5 лет партнёру предложат контракт в другой стране.  
**Варианты:**
- A: Безоговорочно поеду — развитие и масштаб семьи приоритет *(Амбиции)*
- B: Буду против — стабильность и уклад дороже карьеры *(Стабильность)*
- C: Предложу гостевой брак / поиск компромисса *(Баланс)*
- D: Глубокий кризис — мои планы равноценны *(Равноправие)*

### Модуль 7. Тип личности (Big Five адаптивный)
**Шкалы:** S₂₁, S₂₃ + корреляции S₁₂, S₂₄  
**Назначение:** Определяет профиль личности для персонализации рекомендаций и весов в расчёте метрик.
- **Ориентация**: Интроверт / Экстраверт (S₂₃)
- **Честность**: Высокая / Низкая (S₂₁)
- **Эмоциональная устойчивость**: Стабильный / Реактивный (S₁₂, S₂₄)
- **Открытость опыту**: Традиционалист / Инноватор (S₁₆, S₂₄)
- **Доброжелательность**: Компромиссный / Конкурентный (S₉, S₁₁)

*Тип личности учитывается в весах синергии: например, высокий S₂₃ (экстраверсия) даёт бонус к синергии в сфере Близость при совпадении с низким S₂₃ партнёра (интроверт — экстраверт = взаимодополняемость).*

## 4. Спецификация состояний интерфейса (State Machine)

```text
[U1: не пройден] + [U2: не пройден] → State 0: NOT_STARTED
[U1: пройден]    + [U2: не пройден] → State 1: WAITING_FOR_PARTNER (Empty State в «Вместе», личный профиль U₁ активен)
[U1: пройден]    + [U2: пройден]    → State 2: COUPLE_HARMONY_READY (Радар рассчитан, архетип вычислен)
```

### State 1: WAITING_FOR_PARTNER
- Вкладка «Вместе»: **ТОЛЬКО** экран ожидания с именем партнёра и кнопкой напоминания.
- Совместный радар, проценты, бейджи — **СТРОГО НЕ РЕНДЕРЯТСЯ**.
- Вкладка текущего пользователя: показывает **реальные 24 шкали** по 6 блокам.
- Вкладка партнёра: плашка приватности «Ответы станут доступны после завершения».

### State 2: COUPLE_HARMONY_READY
- Вкладка «Вместе»: гексагональный Радар 6 сфер, архетип, карточки точек близости/зон роста с расшифровками статусов.

## 5. Обновлённая схема базы данных (Drizzle ORM)

```ts
// src/server/db/schema.ts (фрагменты)

export const userPsychProfiles = pgTable('user_psych_profiles', {
  userId: uuid('user_id').references(() => users.id, { onDelete: 'cascade' }).primaryKey(),
  coupleId: uuid('couple_id').notNull(),
  sessionId: uuid('session_id').notNull(),
  traitScores: jsonb('trait_scores').notNull(),   // { s1: 45, ..., s24: 60 }

  aAutonomy: numeric(5,2).default('50.00'),
  cCloseness: numeric(5,2).default('50.00'),
  rRepair: numeric(5,2).default('50.00'),
  vFuture: numeric(5,2).default('50.00'),
  consistencyScore: numeric(5,2),
  rawResponses: jsonb('raw_responses'),
  updatedAt: timestamp('updated_at', { withTimezone: true }).defaultNow().notNull()
});

export const coupleReports = pgTable('couple_reports', {
  id: uuid('id').defaultRandom().primaryKey(),
  coupleId: uuid('couple_id').references(() => couples.id).notNull().unique(),
  sessionId: uuid('session_id').references(() => testSessions.id).notNull(),
  radarMetrics: jsonb('radar_metrics').notNull(), // 6 сфер
  radarTrust: numeric(5,2).default('50.00'),
  radarCloseness: numeric(5,2).default('50.00'),
  radarCommunication: numeric(5,2).default('50.00'),
  radarIntimacy: numeric(5,2).default('50.00'),
  radarValues: numeric(5,2).default('50.00'),
  radarLifestyle: numeric(5,2).default('50.00'),
  archetypeTitle: varchar('archetype_title', { length: 255 }).notNull(),
  archetypeDescription: text('archetype_description').notNull(),
  leadSpheres: jsonb('lead_spheres').notNull(),
  synergyPoints: jsonb('synergy_points').notNull(),
  growthZones: jsonb('growth_zones').notNull(),
  blindSpots: jsonb('blind_spots').notNull(),
  personalityTypes: jsonb('personality_types'),    // типы личности обоих партнёров
  calculatedAt: timestamp('calculated_at', { withTimezone: true }).defaultNow().notNull(),
  createdAt: timestamp('created_at', { withTimezone: true }).defaultNow().notNull()
});
```

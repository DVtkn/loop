> Эта страница служит полным справочником для фронтенд-разработчиков и интеграторов, документируя доступные серверные маршруты и требования к авторизации Loop v3.0.0.

# Справочник API (API Reference)

Серверный API построен по стандарту REST с использованием JSON. Все защищённые маршруты требуют передачи сессионного токена в заголовке:  
`Authorization: Bearer <JWT_TOKEN>`.

---

## 1. Системные маршруты и мониторинг

| Метод | Маршрут | Авторизация | Описание |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/health` | Нет | Проверка состояния сервиса, доступности PostgreSQL, времени аптайма и расхода памяти. |
| `POST` | `/api/log-error` | Нет | Приём логов клиентских сбоев UI и ошибок Service Worker. |
| `POST` | `/api/admin/clear-all-data` | Нет (Dev) | Очистка таблиц базы данных на локальных и стейджинг стендах. |

---

## 2. Модуль авторизации и профилей (`/api/auth`)

| Метод | Маршрут | Авторизация | Описание |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/auth/register` | Нет | Регистрация нового аккаунта (логин $\ge 3$ симв., пароль $\ge 6$ симв., пол, имя). |
| `POST` | `/api/auth/login` | Нет | Аутентификация пользователя и выдача подписанного JWT-токена. |
| `GET` | `/api/auth/users` | Нет | Каталог пользователей для поиска партнёра. |
| `GET` | `/api/auth/user/:login` | Да | Получение публичной информации и профиля пользователя. |
| `POST` | `/api/auth/update-profile` | Да | Редактирование профиля (имя, аватар, дата отношений, город, языки любви). |
| `POST` | `/api/auth/change-password` | Да | Безопасная смена пароля с проверкой старого пароля (bcrypt 10 раундов). |
| `POST` | `/api/auth/reset-password` | Нет | Восстановление доступа к учётной записи. |
| `POST` | `/api/auth/sync` | Нет | Быстрая синхронизация состояния аккаунта при холодном старте. |

## 3. Модуль связывания союза (`/api/pair`)

| Метод | Маршрут | Авторизация | Описание |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/pair/request` | Да | Отправка заявки на привязку по логину или короткому коду `LOOP-XXXX`. |
| `POST` | `/api/pair/accept` | Да | Принятие заявки (требует `{ fromLogin, toLogin }`, атомарное создание союза). |
| `POST` | `/api/pair/reject` | Да | Отклонение входящей заявки. |
| `POST` | `/api/pair/disconnect` | Да | Двухшаговый разрыв союза с переводом истории в архивный режим. |
| `GET` | `/api/pair/status/:login` | Да | Получение текущего статуса союза и списка активных заявок. |

## 4. Модуль виртуального питомца Тамагочи (`/api/pet`)

| Метод | Маршрут | Авторизация | Описание |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/pet` | Да | Получение текущего состояния питомца с автоматическим расчётом decay потребностей. |
| `POST` | `/api/pet/birth` | Да | Создание питомца при онбординге: выбор вида (`dog` / `cat`) и клички. Начисляет +50 XP союзу. |
| `POST` | `/api/pet/action` | Да | Выполнение действия заботы (`feed`, `play`, `wash`, `sleep`, `hug`). Начисляет XP питомцу и паре. |
| `POST` | `/api/pet/propose-name` | Да | Предложение смены имени питомца партнёру со статусом ожидания подтверждения. |
| `POST` | `/api/pet/confirm-name` | Да | Подтверждение предложенного имени вторым партнёром. |
| `PATCH`| `/api/pet/switch` | Да | Смена вида питомца (собака $\leftrightarrow$ кошка). |

| :--- | :--- | :--- | :--- |

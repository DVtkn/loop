# База знаний Loop (Wiki)

**Loop** — бережное мобильное веб-приложение для пар, помогающее ежедневно проявлять внимание в один клик, заботиться о совместном виртуальном питомце (Тамагочи), проходить психологические исследования, формировать карту совместимости (Радар 6 сфер) и экологично решать разногласия с поддержкой ИИ-психолога «Сова».

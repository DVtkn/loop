# План развития проекта (Roadmap)

---

## 1. Завершено в релизах v3.0.0 — v3.1.0 (Production Gate Passed)

Все ключевые технические и продуктовые вехи успешно пройдены и проверены в продакшене:

- [x] **Большая Красная Кнопка («Обнять»)**: Hero-компонент экрана «Сегодня», тактильная виброотдача Haptic Feedback, синтез звука биения сердца через Web Audio API, анимация конфетти, мгновенный SSE тост, Smart Polling и Web Push на телефон партнёра.
- [x] **Батарейка заботы партнёра (Care Battery)**: 4 градации энергии, контекстные теги («хочу обнимашек», «нужна тишина», «в ресурсе»), экологичные подсказки партнёру.
- [x] **Честная рулетка бытовых дел Fair Play (Household Roulette)**: 12 категорий обязанностей, защита от спам-кликов и состояния гонки, геймифицированное распределение задач.
- [x] **Виртуальный питомец союза (Тамагочи & Living Pet Avatar)**: Ретро-консоль GameBoy, щенок Чихуахуа и Котёнок, сетка 4-Action Care Grid, ночной режим со звёздным колпаком и подушкой, decay-движок угасания потребностей, атомарное NULL-safe сохранение XP в Neon PostgreSQL (`couple_pets`).
- [x] **Слепой вопрос дня (Blind Reveal Mystery Question)**: Механика честности без подглядывания (ответ партнёра скрыт блюром и замком до собственного ответа), одновременное снятие блокировки при взаимности, блок эмодзи-реакций.
- [x] **Свидания нового поколения**: Интерактивная колода искр (Spark Deck), романтический посадочный талон (Boarding Pass), бенто-коллекции сценариев и Колесо свиданий.
- [x] **Паспорт союза, Deep Talk и Книга заботы (Экран «Мы»)**: Интерактивные карточки откровенных бесед, секретный вишлист (Care Book), запечатанные Капсулы времени с обратным отсчётом.
- [x] **Мобильный юзабилити-редизайн под iPhone**: Устранено ощущение «штурвала самолёта», разгружен хедер, фиксированный bottom tab bar, полноэкранный чат с автоскрытием таб-бара, $0\text{px}$ оверфлоу, защита от автозума Safari iOS ($16\text{px}$ инпуты).
- [x] **8 антиманипулятивных тестов и Радар 6 сфер**: 44 вопроса, 24 психометрические шкалы, строгая детерминированность без нейросетевых галлюцинаций, запрет слова «якорь», аналитика союза с интерактивным планом по Готтману.
- [x] **Инфраструктура, безопасность и надёжность**: Neon Serverless PostgreSQL с Drizzle ORM, Vercel Serverless функции (`api/index.js`), Groq LLM с LRU-кэшированием и детерминированным фоллбэком `psychologyEngine.ts`, строгий Fail-Fast, защита IDOR (`requirePairOwnership`), санитаризация ввода.
- [x] **Тестовое покрытие**: 125/125 тестов Vitest (включая состязательные adversarial-тесты на гонки и защиту кликов) + сквозные тесты Playwright.

## 2. Перспективные продуктовые инициативы (v3.2.0+ — Подготовка к масштабированию)

### 1. Вынос медиа-хранилища в S3 / Cloudflare R2
- **Цель**: Перенос бинарных фото (`BYTEA`) из базы Neon в специализированное объектное хранилище (Cloudflare R2 или AWS S3) с раздачей через CDN. Это предотвратит быстрый рост размера БД при масштабировании на тысячи активных пар.

### 2. Платёжный шлюз и монетизация (Подписка «Одна на двоих»)
- **Цель**: Внедрение подписки для пары (доступ к безлимитным консультациям Совы, расширенным колодам свиданий и архиву). Интеграция с ЮKassa / Т-Банк.

### 3. Виджеты для экранов блокировки (iOS Lockscreen / Android Widget)
- **Цель**: Возможность отправить касание «Обнять» партнёру и посмотреть статус сытости/настроения питомца прямо с заблокированного экрана смартфона в 1 клик.
- **Технологии**: iOS WidgetKit / Android App Widgets через PWA Web App Badging API и Shortcuts.

### 4. Голосовые терапевтические инсайты Совы
- **Цель**: Предоставление паре 2-минутных аудио-подборок от Совы («Голосовая открытка недели») с тёплым анализом динамики отношений, зон внимания и похвалой за совместные успехи.
- **Технологии**: Аудиогенерация на сервере с кешированием в PostgreSQL/S3.

### 5. Синхронизация календаря свиданий и годовщин
- **Цель**: Автоматический экспорт запланированных свиданий из Колеса свиданий и капсул времени в нативные календари Apple Calendar / Google Calendar по протоколу `.ics`.

## 1. Завершено в релизе v3.0.0 (Production Gate Passed)

Все ключевые технические и продуктовые вехи успешно пройдены и проверены в продакшене:

- [x] **Большая Красная Кнопка («Обнять»)**: Hero-компонент экрана «Сегодня», тактильная виброотдача Haptic Feedback, синтез звука биения сердца через Web Audio API, анимация конфетти, мгновенный SSE тост и Web Push на телефон партнёра.
- [x] **Виртуальный питомец союза (Тамагочи)**: Ретро-консоль пары в стиле GameBoy, щенок Чихуахуа и Котёнок, 5 шкал потребностей, ночной режим со звёздным колпаком и подушкой, decay-движок угасания потребностей, сохранение в Neon PostgreSQL (`couple_pets`).
- [x] **Слепой вопрос дня (Blind Reveal Mystery Question)**: Механика честности без подглядывания (ответ партнёра скрыт блюром и замком до собственного ответа), одновременное снятие блокировки при взаимности, блок эмодзи-реакций.
- [x] **Мобильный юзабилити-редизайн под iPhone**: Устранено ощущение «штурвала самолёта», разгружен хедер, фиксированный bottom tab bar, полноэкранный чат с автоскрытием таб-бара, $0\text{px}$ оверфлоу, защита от автозума Safari iOS ($16\text{px}$ инпуты).
- [x] **8 антиманипулятивных тестов и Радар 6 сфер**: 44 вопроса, 24 психометрические шкалы, строгая детерминированность без нейросетевых галлюцинаций, запрет слова «якорь», аналитика союза с рекомендациями для роста.
- [x] **Инфраструктура и надёжность**: Neon Serverless PostgreSQL с Drizzle ORM, Vercel Serverless функции (`api/index.js`), Groq LLM с детерминированным фоллбэком `psychologyEngine.ts`, строгий Fail-Fast и защита IDOR.

## 2. Перспективные продуктовые инициативы (v3.1.0+)

### 1. Виджеты для экранов блокировки (iOS / Android)
- **Цель**: Возможность отправить касание «Обнять» партнёру и посмотреть статус сытости/настроения питомца прямо с заблокированного экрана смартфона в 1 клик.
- **Технологии**: iOS WidgetKit / Android App Widgets через PWA Web App Badging API и Shortcuts.

### 2. Голосовые терапевтические инсайты Совы
- **Цель**: Предоставление паре 2-минутных аудио-подборок от Совы («Голосовая открытка недели») с тёплым анализом динамики отношений, зон внимания и похвалой за совместные успехи.
- **Технологии**: Аудиогенерация на сервере с кешированием в PostgreSQL/S3.

### 3. Синхронизация календаря свиданий и годовщин
- **Цель**: Автоматический экспорт запланированных свиданий из Колеса свиданий и капсул времени в нативные календари Apple Calendar / Google Calendar по протоколу `.ics`.

### 4. Офлайн-устойчивость (PWA Offline First)
- **Цель**: Возможность открывать фотоархив, перечитывать капсулы времени и Книгу заботы в самолёте или при нестабильной связи.
- **Технологии**: Расширение кэша Service Worker (Cache Storage + IndexedDB для локального снимка состояния).

# Тестирование и контроль качества (Testing & QA)

## 1. Философия качества и Definition of Done (DoD)

В проекте Loop действует строгое правило: **функциональность и надёжность важнее декораций**. Ни одна задача не считается выполненной, пока не подтверждена на двух аккаунтах пары и не верифицирована автотестами.

### Чек-лист приёмки (DoD):
1. **End-to-End функциональность**: каждый интерактивный элемент (Большая Красная Кнопка, кнопки консоли Тамагочи A/B/D-Pad, карточки вопросов, колесо свиданий) имеет рабочий обработчик, сохраняющий состояние в базе данных.
2. **Двусторонняя проверка P0-сценариев**: любые механики союза проверяются с точки зрения обоих аккаунтов (пользователь А нажимает/отвечает → пользователь Б видит мгновенное обновление по SSE без рассинхронизации).
3. **Мобильная эргономика (Mobile QA Gate)**:
   - Нулевой горизонтальный скролл ($0\text{px}$ overflow-x).
   - Все интерактивные тач-таргеты не менее $40\times 40\text{px}$.
   - Все поля ввода имеют `font-size: 16px` на мобильных экранах для предотвращения автозума Safari.
4. **Типографика и дизайн-токены**: отсутствие обрезания строк (`truncate`), сохранение цветных пастельных подложек иконок, отсутствие дефолтных outline.
5. **Тесты и сборка**: чистый прогон `npm run test:tsc`, `npm run test` (Vitest) и `npm run build`.

## 2. Набор автотестов и команды запуска

### 1. Юнит-тесты Vitest (`tests/unit/`)
Покрывают изоляцию данных, математику скоринга и ключевые UI-компоненты:
- `tests/unit/isolation.test.tsx` — проверка строгой изоляции данных пары (IDOR, 401/403).
- `tests/unit/tradeOff.test.tsx` — валидация распределения баллов и вопросов с принудительным выбором.
- `tests/unit/soundFx.test.ts` — проверка генерации Web Audio синтезатора звука.

Запуск:
```bash
npm run test
```

### 2. Строгая проверка типов TypeScript
```bash
npm run test:tsc
```

### 3. Сквозные браузерные тесты Playwright (`e2e/`)
Проверяют полный сценарий: регистрация двух пользователей, обмен заявками пары, синхронный ответ на вопрос дня со снятием слепой блокировки, нажатие Большой Красной Кнопки с проверкой тоста у партнёра.

Запуск:
```bash
npm run test:e2e
```

### 4. Мобильный юзабилити-аудит (iPhone 15 Pro Emulation)
Специализированный Playwright-скрипт эмуляции смартфона с замером геометрии экрана:
- Контроль горизонтального вылета ($0\text{px}$ overflow-x);
- Проверка размера шрифтов полей ввода ($\ge 16\text{px}$);
- Проверка тач-таргетов кнопок хедера и нижнего таб-бара ($\ge 40\text{px}$).
